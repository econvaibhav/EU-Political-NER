# Small examples

`mentions.csv` contains illustrative mentions selected to exercise the project's rules. None of the rows is a respondent record. Their spelling variants occur in the supplied references or notebooks.

`PS` shows the role of country context. `Donald Trump` in a French response shows why source country and actor country differ. `Le Pen` illustrates why a surname deserves review even if the dictionary suggests a name. `Greens` only receives the special Sweden correction when the CLI flag is enabled.

`example_results.jsonl` is the default review-mode output from the supplied snapshot. It is a demonstration of program behaviour, not manually adjudicated ground truth.
